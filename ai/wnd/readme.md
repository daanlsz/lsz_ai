## prompt 设计过程
- 创建一个网页来帮我写生日贺卡（Goal）,
    它应该会给我返回一条有趣的信息。

    如果不满意，接着prompt ,沉静在vibe coding 的海洋中
    -加上节日风格的标题和配色，让它更好看些
    -把卡片放在右侧展示，让它看起来向生日卡片的内页 Layout
    -在页面的顶部加一个有趣的标题，另外，不要替换掉旧卡片，而是
    保留他们并叠放在新卡片的下方。Features特点
    当我们用AI写代码时，不是随意去写prompt，通常从一组基本指令开始
     prompt 基本块
     Goal+Input+Output+Layout+Features


     创建一个网页来帮我写生日贺卡。
     当输入一个人的姓名、年龄和爱好后，它应该返回一个有趣的消息。
     使用喜庆的标题和配色。
     把贺卡显示在右侧，并且让它看起来想生日贺卡的内页。
     在页面底部添加一个有趣的标题。
     另外，不要替换旧的贺卡，而是保留他们的显示状态，把他们堆叠在新卡片的下方。

     AI擅长的是执行准确清晰的指令
